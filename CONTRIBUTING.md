# Contributing to BTU Tech Spark ⚡

> **"Everyone can use this repository, and everyone is welcome to the repository."**

Welcome! Whether you are a first-semester student writing your first line of code, an experienced builder exploring AI and open source, or simply curious about technology — **you belong here**.

This repository powers the official website and community hub for **BTU Tech Spark** (BTU Tech Hub), a student-led tech community at **BTU Cottbus-Senftenberg**.

---

## 🌟 Our Core Motto

### **Connect • Learn • Build**

- **Connect**: Meet fellow students, makers, thinkers, and tech enthusiasts. Build lasting friendships and professional networks without barriers.
- **Learn**: Share knowledge across modern domains — AI & LLMs, Full-Stack Web Development, Open Source, Cloud, System Design, and Career Prep.
- **Build**: Turn concepts into real projects. We don't just talk about technology — we code, ship, test, and present our ideas together.

## 🤝 How You Can Contribute

Contributions don't just mean writing complex code! There are many meaningful ways to contribute:

### 1. Document a Meetup
Each week we hold a meetup, and its notes live right in `src/content/meetups/meetup-XX.md`.
- Add summaries of what was discussed or presented.
- Share resources, helpful links, or slides from members.

### 2. Share Photos
Have photos from our Sunday sessions or hack nights?
- Add them to `src/content/images-meetup/meetup-XX/`.
- Run `npm run generate-thumbs` to automatically generate optimized thumbnails!

### 3. Showcase Your Projects
Built something cool during the week or at a hackathon?
- Add your project to the showcase in `src/components/ProjectsSection.tsx` or present it during a Sunday session.

### 4. Improve the Website
- **Fix bugs or typos**: Notice something misaligned or misspelled? Send a quick fix!
- **Improve UI/UX**: Enhance animations, accessibility, mobile responsiveness, or dark theme styling.
- **Add features**: Propose new features that help the BTU community stay informed and connected.

## 🚀 Quick Development Setup

To test your changes locally:

```bash
# 1. Clone your fork
git clone https://github.com/<your-username>/btu-tech-spark.git
cd btu-tech-spark

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Run tests and linter
npm test
npm run lint
```

---

## 🌿 Contribution Workflow

1. **Fork** the repository and create a new feature branch:
   ```bash
   git checkout -b feature/your-idea-name
   ```
2. **Make your changes**: Keep commits clear and descriptive.
3. **Verify**: Ensure the project compiles cleanly:
   ```bash
   npm run lint
   npm test
   npm run build
   ```
4. **Push** to your fork and submit a **Pull Request (PR)**!
5. We will review your PR with excitement, provide supportive feedback, and merge it!

## 💖 Community Values & Code of Conduct

- **Be welcoming & kind**: Treat everyone with respect, encouragement, and patience.
- **Beginner-friendly**: Remember that everyone was a beginner once. No question is silly.
- **Collaborative over competitive**: We thrive when we help each other succeed.
- **Keep it open**: Share open-source knowledge, tools, and ideas freely.
